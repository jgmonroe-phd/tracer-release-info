## Download and open TRACER on Windows

1. **Download the Windows package or executable** using the download link above.
2. **If it is a ZIP:** right-click it, choose **Extract All**, and open the extracted folder. Keep the extracted files together.
3. **Open TRACER:** double-click the file ending in `.exe`. For a ZIP package, run it from the extracted folder; a standalone `.exe` can be opened directly.

If you browse GitHub's release page, choose the named TRACER download under **Assets**. The automatically listed **Source code** archives are not the application.

## How do I know when to update?

TRACER checks release policy when it runs. Enforcement-capable builds require internet and authenticated GenAI access. A version may first show an update warning and later stop until it is updated. If an update is required, return to this page and get the recommended download. Older builds retain their original behavior until replaced.

Close TRACER before opening the new version. Keep your documents and other working files when replacing an older copy of the application.

If you use GitHub, you can also choose **Watch → Custom → Releases** on this repository to subscribe to release notifications.

## Need help?

[Report a download or start-up problem](https://github.com/jgmonroe-phd/tracer-release-info/issues/new). Include your Windows version, the TRACER version, and the error message. Leave out private documents and personal information.

If Windows or your organization blocks the application, contact your IT team or the TRACER maintainer for help.
