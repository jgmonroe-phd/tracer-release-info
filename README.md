# TRACER downloads

Get the TRACER application here. Choose the download for your computer, then follow the steps below.

[Open the download page](https://jgmonroe-phd.github.io/tracer-release-info/) · [Browse all releases](https://github.com/jgmonroe-phd/tracer-release-info/releases)

## Which file do I need?

The first TRACER package is for **64-bit Windows (Intel or AMD)**. A Mac, Linux, or native Windows ARM package has not been provided. If you are unsure which Windows system you have, open **Settings → System → About** and check **System type**.

## Download and open TRACER on Windows

1. **Download the ZIP** using the download link above.
2. **Extract it:** find the ZIP in your Downloads folder, right-click it, and choose **Extract All**. Open the extracted folder.
3. **Open TRACER:** double-click the TRACER application, the file ending in `.exe`. Run it from the extracted folder.

For version 0.8.8, the download is `TRACER_v0.8.8.zip` and the application inside is `TRACER_v0.8.8.exe`.

If you browse GitHub's release page, choose the named TRACER download under **Assets**. The automatically listed **Source code** archives are not the application.

## How do I know when to update?

TRACER can check for a newer version when it runs. If it reports that an update is available, return to this page and get the recommended download.

Close TRACER before opening the new version. Keep your documents and other working files when replacing an older copy of the application.

If you use GitHub, you can also choose **Watch → Custom → Releases** on this repository to subscribe to release notifications.

## Need help?

[Report a download or start-up problem](https://github.com/jgmonroe-phd/tracer-release-info/issues/new). Include your Windows version, the TRACER version, and the error message. Leave out private documents and personal information.

If Windows or your organization blocks the application, contact your IT team or the TRACER maintainer for help.
