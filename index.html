Get started on Windows

  1. Download the ZIP file

    Use the Windows download above and save it somewhere easy to find, such as your Downloads folder.

  2. Extract the files

    Right-click the downloaded ZIP file, select Extract All…, and choose Extract.

  3. Open TRACER

    In the extracted folder, open the TRACER .exe file. Open it from this folder after extraction.
